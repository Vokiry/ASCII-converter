## 🌟 Возможности (Features)

### 1. Предельная простота для не-технарей (Zero-Friction UX)
* **Портативный бинарник:** Никаких интерпретаторов, виртуальных машин, Python или Node.js. Один запускаемый файл без внешних зависимостей.
* **Перетаскивание (Drag & Drop):** Просто перетащите любую картинку или GIF в окно программы.
* **Вставка из буфера обмена (`Ctrl+V`):** Сделайте скриншот и сразу вставьте его в приложение!
* **Большая кнопка «Скопировать арт»:** Одно нажатие (или `Ctrl+C`) — и готовый ASCII-текст уже в буфере обмена с удобным уведомлением.
* **Встроенный пример:** Кнопка «🧪 Пример» генерирует красивое тестовое изображение с градиентами и CRT-монитором для мгновенного знакомства с программой.

### 2. Системные шрифты и сохранение пропорций (System Fonts)
* **Автоопределение системного моноширинного шрифта:** Программа автоматически считывает системный моноширинный шрифт операционной системы (*Noto Sans Mono*, *Consolas*, *Cascadia Mono*, *Menlo* и др.) и использует его как для отрисовки интерфейса, так и для экспорта в картинку. Благодаря этому арт выглядит **абсолютно одинаково** как в окне приложения, так и при копировании в блокнот или терминал!
* **Компенсация формы символа (Aspect Ratio):** Моноширинные символы вдвое выше своей ширины (~1:2). Программа автоматически корректирует пропорции, предотвращая искажения.

### 3. Алгоритмы конвертации
* **70- и 10-символьные градиенты плотности:** Полная шкала полутонов.
* **Символы Брайля (Unicode Braille 2x4):** Ультра-детализация с разрешением **в 8 раз выше** обычного ASCII-арта за счет использования субпиксельных точек Unicode (`U+2800` .. `U+28FF`).
* **Контурный скетч (Sobel Edge Detection):** Выделение граней оператором Собеля с вычислением направления градиента (`|`, `-`, `/`, `\`).
* **Блочные символы Unicode:** Винтажный стиль ` ░▒▓█`.
* **Продвинутый дизеринг:**
  * *Floyd-Steinberg* (плавные тени и фотографические градиенты)
  * *Atkinson* (классический стиль раннего Macintosh)
  * *Bayer 4x4* (ретро-матричная сетка)
  * *Threshold* (прямой порог)

### 4. Цветовые режимы
* **Монохром:** Классический ч/б или светлый текст на темном фоне.
* **Ретро CRT (P1 Phosphor):** Знаменитый зеленый люминофор терминалов 80-х.
* **Янтарный экран (Amber CRT):** Тёплое янтарное свечение.
* **Киберпанк (Неон):** Неоновые переливы Cyan & Magenta.
* **TrueColor (24-bit RGB):** Полноцветное отображение каждого символа в соответствии с оригинальными цветами пикселей!

### 5. Поддержка анимированных GIF
* Загрузка многокадровых анимированных файлов `.gif`.
* Встроенный плеер: воспроизведение, пауза, покадровый переход, таймлайн.
* Экспорт в анимированный GIF, где каждый кадр отрендерен в виде ASCII-арта!

### 6. Богатый экспорт
* **В буфер обмена:**
  * Обычный текст (`Ctrl+C`)
  * Готовая картинка PNG в буфер обмена
  * Markdown-блок для GitHub/Discord
* **В файл (`Ctrl+S`):**
  * `.png` (растеризация текста в высоком разрешении с системным шрифтом)
  * `.jpg` (с оптимизацией размера)
  * `.txt` (чистый моноширинный текст)
  * `.html` (автономная веб-страница со встроенными стилями)
  * `.svg` (масштабируемая векторная графика)
  * `.gif` (анимированный GIF)

## 🚀 Быстрый запуск

### Требования
* Rust 1.85+ (если вы собираете из исходного кода): [rustup.rs](https://rustup.rs/)

### Сборка и запуск
```bash
# Клонировать репозиторий
cd ASCII-converter

# Запуск в режиме разработки
cargo run

# Сборка оптимизированного релизного файла
cargo build --release

# Исполняемый файл будет доступен в:
# target/release/ascii-converter (Linux/macOS)
# target/release/ascii-converter.exe (Windows)
```

## ⌨️ Горячие клавиши (Hotkeys)

| Клавиши | Действие |
|---|---|
| `Ctrl + V` | Вставить изображение из буфера обмена |
| `Ctrl + C` | Скопировать ASCII текст в буфер обмена |
| `Ctrl + O` | Открыть файл с диска |
| `Ctrl + S` | Сохранить файл (PNG, TXT, HTML, SVG, GIF) |
| `Space` | Воспроизведение / Пауза для анимации GIF |
| `Ctrl + +` / `Ctrl + -` | Приблизить / Отдалить предпросмотр |
| `Ctrl + 0` | Сбросить масштаб к 100% |

## 🏗️ Архитектура проекта

```
src/
├── main.rs                  # Точка входа eframe, настройка нативного окна
├── lib.rs                   # Публичные модули библиотеки
├── app.rs                   # GUI интерфейс (egui), панели, шорткаты
├── system_font.rs           # Кроссплатформенный поиск системного моношрифта
├── presets.rs               # Базовые пресеты («Терминал», «Матрица», «Брайль» и др.)
├── clipboard.rs             # Работа с буфером обмена (текст и картинки через arboard)
├── sample_image.rs          # Генератор встроенного тестового изображения
└── engine/                  # Ядро конвертации
    ├── mod.rs               # Оркестратор параллельной конвертации (Rayon)
    ├── types.rs             # Структуры конфигурации, цветов и алгоритмов
    ├── luminance.rs         # Взвешенная яркость (Rec. 709), гамма, контраст
    ├── dithering.rs         # Floyd-Steinberg, Atkinson, Bayer 4x4
    ├── edge.rs              # Оператор Собеля и направленные символы
    ├── braille.rs           # Матрица Брайля 2x4 (8x разрешение)
    ├── palettes.rs          # Палитры символов и плотности
    ├── frame.rs             # Модель кадра (экспорт в текст, HTML, SVG)
    ├── renderer.rs          # Рендеринг текста в PNG/JPEG через fontdue
    └── gif_handler.rs       # Декодирование, покадровая конвертация и экспорт GIF
```

## 🧪 Тестирование

Проект полностью покрыт автоматическими тестами:
```bash
cargo test
```
Тесты проверяют:
* Вычисление воспринимаемой яркости и гаммы.
* Алгоритмы дизеринга (Floyd-Steinberg, Atkinson, Bayer).
* Корректность матриц Брайля 2x4 и оператора Собеля.
* Рендеринг в PNG и JPEG с соблюдением стандартов кодеков.
* Экспорт в форматы HTML, SVG, TXT, Markdown.
* Покадровую раскадровку и повторный экспорт анимаций GIF.
* Поиск и парсинг системного шрифта.
